# Reference artifacts

## Accepted demo

`accepted-demo.html` is the standalone desktop HTML that passed manual visual acceptance. It is a design and interaction reference, not production application code.

The reference covers:

- Three-column desktop layout with a persistent income panel.
- Pinned home and category editing views.
- Search, profile, theme picker, and seven approved themes.
- The approved top-bar and side-panel gradient treatment.
- Responsive behavior and the 50-goal information architecture.

## Legacy draft

`legacy-draft/` is an immutable snapshot of the uncommitted proof of concept that existed before the React repository initialization. Its tax engine and tests will be deliberately migrated during Phase 2. Do not treat its UI as the accepted visual baseline.
